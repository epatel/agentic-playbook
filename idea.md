The 4 areas of work for a software developer
* Computer Science - what we know about the computer and what is run on it
* Software Engineering - things done to work together
* Craftmanship - personal trait knowing the tools
* Innovation - creativity, problemsolving

Agentic tools changes everything. They *are* efficient and good when used "correctly". Agentic developer maybe need to know less about Computer Science but should know about technologies. Currently there is really no declared way of working as a team, the engineering part set yet, a little like the situation before Git and Scrum. The new need developers to learn the new tools and experiment to investigate their usability. And for innovation developers need to understand the new tools to be able to solve new problems.
