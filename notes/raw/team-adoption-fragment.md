With the emerging agentic tools I have seen that now initially companies does
not know how to implement usage in any engineering structured way. One analogy
I have is how different and adhoc many project was before many project settled
for Scrum and Git as way of working. Today I see company managers want
developer to use agentic tools but there is no managmental direction how to
do it. Here I see the need for a playbook kind of process to start to implement
a way of working with agentic tools for a team. First some steps to collect
what the team have done until now. Maybe open discussion how the tools work
and why somethings work better than others. Then the goal is to define a way
of working with the new tools. Also trying to get the developers with the
help of the agentic tools getting similar result.

I think it is also important to come back and redo these discussions as
this area is a moving target and new tools are introduced regularly. Maybe
even add room for experimenting with new tools.

It also has to be presented in a way not to scare but rather build trust.
Either fully transparent and humbly.
